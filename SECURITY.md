# Security Policy

## Supported Versions

Conduit API is pre-release software. Security fixes are provided only for the
latest code on the default branch and the latest published alpha release.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory flow for this repository and include:

- affected version or commit;
- impact and required preconditions;
- reproduction steps or a minimal proof of concept;
- suggested mitigation, when known.

Do not access data that is not yours, degrade shared services, or retain
sensitive data while researching an issue. Maintainers will acknowledge a
complete report through the advisory and coordinate disclosure after a fix is
available.
